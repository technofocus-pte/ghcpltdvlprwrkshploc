**ラボ 01: GitHub リポジトリとブランチを作成する**

目的：

あなたがソフトウェア開発に不慣れで、バージョン管理とコラボレーションに
GitHub
を使用するチームに参加したと想像してください。プロジェクトに効果的に貢献し、オープンソース
コミュニティに参加するには、GitHub
のコア概念と機能をしっかりと理解する必要があります。

このラボでは、次のことを行います。

- テンプレートからリポジトリを作成する

- ブランチの作成:
  リポジトリに新しいブランチを作成する練習をして、並列開発とブランチが独立した作業をどのように促進するかを調べます。

演習 \#1: テンプレートとリポジトリ内のブランチからリポジトリを作成する:

1.  GitHub アカウントにサインインします。

2.  次のリンクを参照します:
    **https://github.com/skills/introduction-to-github**

このラボでは、パブリック テンプレート
"**skills-introduction-to-github**"を使用してリポジトリを作成します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image1.jpeg)

3.  「**Create a new repository」**メニュー の**「Use this
    template」**を選択します 。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image2.jpeg)

4.  次の詳細を入力し、「**Create Repository」**を選択します。

    - リポジトリ名: **skills-introduction-to-github**

    - リポジトリの種類: **パブリック**

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image3.jpeg)

5.  リポジトリのヘッダーメニューにある **「コード**」タブに移動します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image4.jpeg)

6.  メインブランチのドロップダウンをクリックします。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image5.jpeg)

7.  「**ブランチの検索」**フィールドに、「**my-first-branch」**という名前を入力し**、「**Create
    branch **my-first-branch** from main」を選択します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image6.jpeg)

8.  ブランチは、作成したブランチに自動的に切り替わります。メインブランチのドロップダウンバーには、新しいブランチが反映され、新しいブランチ名が表示されます。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image7.jpeg)

概要：

このラボでは、

- 新しい Git リポジトリを初期化して、プロジェクトの追跡を開始しました。

- コードのさまざまな機能やバージョンを管理するためのブランチを作成するプロセスを理解しました。
