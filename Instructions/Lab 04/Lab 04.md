**Laboratório 04: Revisar solicitações pull e resolver conflitos de
divergências**

Objetivo:

Imagine que você faz parte de uma equipe de desenvolvimento trabalhando
em um projeto com vários colaboradores. À medida que as alterações são
feitas, é fundamental revisá-las e garantir que o trabalho de todos se
integre perfeitamente. Você precisa colaborar de forma eficaz,
gerenciando solicitações pull e resolvendo conflitos de divergências
para manter a integridade do projeto e evitar interrupções.

Neste laboratório prático, você se concentrará em dois aspectos
essenciais da colaboração no GitHub:

- Criar uma solicitação pull: selecione os branches apropriados, forneça
  um título e uma descrição e envie uma solicitação pull para propor
  alterações.

- Revisar solicitações pull: examine as alterações propostas nas
  solicitações pull, garantindo que elas atendam aos padrões do projeto
  e estejam prontas para integração.

- Resolver conflitos de divergências: pratique a resolução de conflitos
  que surgem quando alterações em diferentes branches afetam as mesmas
  partes de um arquivo, garantindo uma integração e colaboração
  tranquilas.

Exercício nº 1: Criar um repositório a partir de um modelo e criar uma
solicitação pull

A solicitação pull mostrará as alterações em seu branch para outras
pessoas. Essa solicitação pull manterá as alterações que você acabou de
fazer em seu branch e proporá aplicá-las ao branch principal.

2.  Navegue até o seguinte
    link: https://github.com/skills/review-pull-requests

"**skills-review-pull-requests**".
