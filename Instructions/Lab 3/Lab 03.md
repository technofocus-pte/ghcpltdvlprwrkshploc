**ラボ 03: GitHub Pages と Jekyll を使用してオンライン
ポートフォリオを作成する**

目的：

あなたがテクノロジースタートアップの新進気鋭のソフトウェア開発者で、オンライン
ポートフォリオを通じて自分のプロジェクト、スキル、経験を紹介したいと熱望していると想像してください。自分の作品を表示するためのプロフェッショナルなプラットフォームが必要なので、GitHub
Pages を使用して個人の Web
サイトまたはブログを作成することにしました。このプラットフォームを使用すると、GitHub
リポジトリを活用して、Web サイトを簡単に公開および保守できます。

このハンズオンラボでは、次のことを行います:

- GitHub リポジトリの作成:
  個人サイトの基盤となる新しいリポジトリを設定します。

- GitHub Pagesを有効にする:
  リポジトリから直接WebサイトをホストするようにGitHub
  Pagesを構成します。

- Jekyll を使用して最初のサイトを展開する: 人気の静的サイト
  ジェネレーターである Jekyll を利用して、最小限の労力でプロ並みの Web
  サイトを構築して展開します。

演習 \#1: テンプレートからリポジトリを作成する

1.  GitHub アカウントにサインインします。

2.  次のリンクを参照します: https://github.com/skills/github-pages

このラボでは、パブリックテンプレート「**skills-github-pages**」を使用してリポジトリを作成します。

3.  「**このテンプレートを使用する」**メニューの**「Create a new
    repository」** を選択します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image2.jpeg)

4.  次の詳細を入力し、「**Create Repository」**を選択します。

    - リポジトリ名: **skills-github-pages**

    - リポジトリの種類: **Public**

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image3.jpeg)

これで、GitHub ページを含む Web
