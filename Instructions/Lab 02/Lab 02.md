**Laboratoire 2 : Communiquer à l'aide de Markdown**

Objectif:

Imaginez que vous travaillez sur un projet collaboratif avec votre
équipe de développement. La communication et l'organisation sont
essentielles à la réussite du projet. Markdown est un outil crucial pour
les développeurs comme vous afin d'améliorer la clarté et l'organisation
de votre communication, en particulier dans le traitement des
**problèmes (issues)** et des **demandes de tirage (pull requests)**.

Dans cet atelier, vous allez :

- Créez un référentiel à l'aide d'un modèle public pour commencer
  rapidement.

- Générez des pull requests pour proposer des modifications et
  comparez-les efficacement.

- Modifiez votre fichier pour inclure des en-têtes et validez ces
  modifications, ce qui rend votre documentation plus structurée et plus
  lisible.

Tâche \#1 : Créer un dépôt à l'aide d'un modèle public

1.  Connectez-vous à votre compte GitHub.

2.  Naviguez jusqu'au lien suivant :
    https://github.com/skills/communicate-using-markdown

Dans cet atelier, vous allez créer le référentiel à l'aide d'un modèle
public « **skills-communicate-using-markdown** ».

![](./media/image1.jpeg)

3.  Sélectionnez **Create a new repository** dans le menu **Use this
    template**.

être incorrect.](./media/image2.jpeg)

4.  Entrez les détails suivants et sélectionnez **Créer un
    référentiel**.

    - Nom du dépôt : **skills-communicate-using-markdown**

    - Type de référentiel : **Public**

Tâche \#2 : Créer des demandes de tirage et comparer les modifications

1.  Sur la page **skills-communicate-using-markdown**, sélectionnez l'
    onglet **Pull requests** dans le volet de navigation supérieur.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut

2.  Sur la page suivante, sélectionnez le bouton **New pull request**.

![Une capture d'écran d'une page web Le contenu généré par l'IA peut
être incorrect.](./media/image5.jpeg)

3.  Sur la page **Compare changes**, sélectionnez **base : main** et
    **compare : start-markdown**

**Remarque :** Il est généralement nécessaire d'attendre quelques
secondes et d'actualiser la page pour afficher les branches.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut

11. \# Hello World

12. \## This is an \`\<h1\>\` header, which is the largest

13. \### This is an \`\<h2\>\` header

\#### This is an \`\<h6\>\` header, which is the smallest

Résumé:

Vous avez maintenant créé un dépôt, généré des demandes de tirage (pull
requests) et structuré votre documentation Markdown avec des en-têtes
(headers). Ce flux de travail améliorera considérablement votre capacité
à communiquer et à vous coordonner efficacement avec votre équipe.
