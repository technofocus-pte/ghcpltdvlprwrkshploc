**Laboratório 01: Criar um repositório e um branch no GitHub**

Objetivo:

Imagine que você é novo no desenvolvimento de software e entrou para uma
equipe que usa o GitHub para controle de versão e colaboração. Para
contribuir efetivamente com seus projetos e interagir com a comunidade
de código aberto, é necessário ter uma compreensão sólida dos conceitos
e funcionalidades principais do GitHub.

Neste laboratório, você irá:

- Criar um repositório a partir de um modelo

- Criar um branch: Praticar a criação de um novo branch em um
  repositório para explorar o desenvolvimento paralelo e como os
  branches facilitam o trabalho independente.

Exercício nº 1: Criar um repositório a partir de um modelo e um branch
dentro do repositório

1.  Acesse sua conta do GitHub.

2.  Vá para o seguinte link:
    https://github.com/skills/introduction-to-github

Neste laboratório, você criará o repositório usando um modelo público
**"skills-introduction-to-github"**.

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image1.jpeg)

3.  Selecione **Create a new repository** no menu **Use this template**.

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image2.jpeg)

4.  Insira as seguintes informações e selecione **Create Repository**.

    - Repository name: **skills-introduction-to-github**

    - Repository type: **Public**

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image3.jpeg)

5.  Navegue até a guia **Code** no menu do cabeçalho do seu repositório.

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image4.jpeg)

6.  Clique na lista suspensa do branch main.

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image5.jpeg)

7.  No campo **Find a branch**, insira o nome **my-first-branch** e
    selecione **"**Create branch **my-first-branch** from main**"**.

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image6.jpeg)

8.  O branch será automaticamente alternado para aquele que você acabou
    de criar. A barra suspensa do branch principal refletirá seu novo
    branch e exibirá o nome dele.

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image7.jpeg)

Resumo:

Neste laboratório, você:

- Inicializou um novo repositório Git para começar a rastrear seus
  projetos.

- Entendeu o processo de criação de branches para gerenciar diferentes
  funcionalidades ou versões do seu código.
