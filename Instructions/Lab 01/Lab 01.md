**Laboratorio 01: Crear un repositorio y una rama en GitHub**

Objetivo:

Imagine que es nuevo en el desarrollo de software y se ha incorporado a
un equipo que utiliza GitHub para control de versiones y colaboración.
Para contribuir eficazmente a sus proyectos y participar en la comunidad
de código abierto, necesita tener un entendimiento sólido de los
conceptos y funcionalidades principales de GitHub.

En este laboratorio, usted:

- Creará un repositorio a partir de una plantilla.

- Crear una rama: Practicará la creación de una nueva rama en un
  repositorio para explorar el desarrollo en paralelo y cómo las ramas
  facilitan el trabajo independiente.

Ejercicio n.º 1: Crear un repositorio a partir de una plantilla y una
rama dentro del repositorio.

1.  Inicie sesión en su cuenta de GitHub.

2.  Navegue al siguiente
    enlace: https://github.com/skills/introduction-to-github

En este laboratorio, creará el repositorio utilizando una plantilla
pública "**skills-introduction-to-github**".

3.  Seleccione **Create a new repository** en el menú **Use this
    template**.

![A screenshot of a computer AI-generated content may be

4.  Ingrese los siguientes detalles y seleccione **Create Repository**.

    - Repository name: **skills-introduction-to-github**

    - Repository type: **Public**

![A screenshot of a computer AI-generated content may be

7.  In the **Find a branch** field, enter the
    name **my-first-branch** and select "Create

8.  La rama cambiará automáticamente a la que acaba de crear. La barra

Resumen:

En este laboratorio, usted ha

- Inicializado un nuevo repositorio de Git para comenzar a rastrear sus
  proyectos.

- Comprendido el proceso de creación de ramas para administrar
  diferentes características o versiones de su código.
