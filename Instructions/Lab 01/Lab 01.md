**Laboratoire 01 : Création d'un dépôt GitHub et d'une branche**

Objectif:

Imaginez que vous débutez dans le développement de logiciels et que vous
avez rejoint une équipe qui utilise GitHub pour le contrôle de version
et la collaboration. Pour contribuer efficacement à vos projets et
interagir avec la communauté open source, vous devez avoir une solide
compréhension des concepts et fonctionnalités de base de GitHub.

Dans cet atelier, vous allez :

- Créer un référentiel à partir d'un modèle

- Créer une branche : entraînez-vous à créer une nouvelle branche dans
  un dépôt pour explorer le développement parallèle et la façon dont les
  branches facilitent le travail indépendant.

Exercice \#1 : Créer un dépôt à partir d'un modèle et d'une branche au
sein du dépôt

1.  Connectez-vous à votre compte GitHub.

2.  Naviguez jusqu'au lien suivant :
    https://github.com/skills/introduction-to-github

Dans cet atelier, vous allez créer le dépôt à l'aide d'un modèle public
« **skills-introduction-to-github** ».

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image1.jpeg)

3.  Sélectionnez **Create a new repository** dans le menu **Use this
    template**.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image2.jpeg)

4.  Entrez les détails suivants et sélectionnez **Create Repository**.

    - Nom du dépôt : **skills-introduction-to-github**

    - Type de référentiel : **Public**

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image3.jpeg)

5.  Accédez à l' onglet **Code** dans le menu d'en-tête de votre dépôt.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image4.jpeg)

6.  Cliquez sur le menu déroulant de la branche principale.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image5.jpeg)

7.  Dans le champ **Find a branch**, entrez le nom **my-first-branch**
    et sélectionnez « Create branch **my-first-branch** from main »

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image6.jpeg)

8.  La branche basculera automatiquement vers celle que vous venez de
    créer. La barre déroulante de la branche principale reflétera votre
    nouvelle branche et affichera le nom de la nouvelle branche.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image7.jpeg)

Résumé:

Dans cet atelier, vous avez

- Initialisez un nouveau référentiel Git pour commencer à suivre vos
  projets.

- Compréhension du processus de création de branches pour gérer
  différentes fonctionnalités ou versions de votre code.
