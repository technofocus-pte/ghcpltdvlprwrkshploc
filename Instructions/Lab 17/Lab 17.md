**ラボ 17: GitHub リポジトリでシークレット
スキャンを有効にし、トークンをコミットする**

共有 GitHub リポジトリを使用してチーム
プロジェクトに取り組んでいるソフトウェア開発者であると想像してください。コードが安全に保たれ、偶発的な漏洩がないようにするために、シークレット
スキャン --- API
トークンやパスワードなどの機密情報が誤ってリポジトリにコミットされる可能性のある機密情報を特定するのに役立つ機能を実装することにしました。

目的：

このハンズオンラボでは、次のことを行います。

1.  シークレットスキャンを有効にする:
    GitHubリポジトリでシークレットスキャンを構成して、機密情報を自動的に検出してフラグを立てます。

2.  トークンをコミットする:
    トークンまたはその他の機密情報をリポジトリに意図的に追加して、シークレット
    スキャン機能の有効性をテストします。

演習 \#1: GitHub リポジトリを作成し、シークレット スキャンを有効にする

タスク \#1: テンプレートを使用したリポジトリの作成

1.  GitHub アカウントにサインインします。

2.  次のリンクを参照します:
    https://github.com/skills/introduction-to-secret-scanning

このラボでは、パブリックテンプレート「**skills-introduction-to-secret-scanning**」を使用してリポジトリを作成します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image1.jpeg)

3.  「**このテンプレートを使用する**」メニューの**「Create a new
    repository** **」** を選択します 。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image2.jpeg)

4.  次の詳細を入力し、「**Create Repository」**を選択します。

    - リポジトリ名: **skills-introduction-to-secret-scanning**

    - リポジトリの種類: **Public**

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image3.jpeg)

タスク \#2: シークレット スキャンを有効にする

1.  新しく作成したリポジトリのランディングページで、上部のナビゲーションバーから「**設定**」を選択します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image4.jpeg)

2.  サイドバーの**「セキュリティ**」セクションで、「**Code security and
    analysis」**を選択します。

**注**:
「**セキュリティ**」メニューを表示するには、下にスクロールする必要があります

![ブラウザーウィンドウのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image5.jpeg)

3.  ページの一番下までスクロールし、シークレット
    スキャンを**有効にする** をクリックします。

**注:** 「**Disable**」
ボタンが表示されている場合は、リポジトリでシークレット
スキャンが既に有効になっていることを意味します。

![白い背景に黒いテキスト AI
が生成したコンテンツは間違っている可能性があります。](./media/image6.jpeg)

まだ有効になっていない場合は、以下に示すように**有効化**ボタンが表示されます。

![コンピューターエラーのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image7.jpeg)

**注:**
シークレット・スキャンが有効になっている場合、リポジトリー内の資格情報に関する電子メール通知が、アカウントに関連付けられたメール
ID
に送信されます。このスキルリポジトリのトークンは非アクティブです。環境へのリスクはありません。

このリポジトリでシークレット
スキャンが有効になったので、新しいトークンをコミットして、それがどのように機能するかを確認しましょう。

演習 \#2: トークンをコミットする

この演習では、AWS キーとアクセス ID
をリポジトリにコミットします。これは、AWS
へのログインに使用できない非アクティブなトークンです。

1.  メイン ナビゲーション
    バーの左上のペインで、「**コード**」タブをクリックし、**credentials.yml**ファイルを選択します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image8.jpeg)

2.  右側の「編集」ボタンをクリックします。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image9.jpeg)

3.  次のテキストをコピーして、**credentials.yml**ファイルの編集ペインの既存のコードの下に貼り付けます。

4.  default:

5.  aws_access_key_id: AKIAQYLPMN5HNM4OZ56B

6.  aws_secret_access_key: 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

7.  output: json

region: us-east-2

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image10.jpeg)

8.  右上隅にある**「Commit changes」**ボタンをクリックし、「**Commit
    Changes」**ウィンドウで「**Commit
    Changes」**をもう一度クリックします。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image11.jpeg)

**注:** 変更をコミットすると、GitHub
アカウントに関連付けられたメールボックスにアラートが届きます。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image12.jpeg)

概要：

これで、コードとデータを保護するためにシークレットスキャンを有効にしてテストする方法を実際に理解しました。
