**Laboratoire 06 : Améliorer la collaboration avec GitHub : Rechercher
et résoudre les problèmes liés**

Objectifs:

Imaginez que vous travaillez sur un projet collaboratif avec une équipe
de développement, et que la gestion efficace des problèmes et des
demandes de tirage est cruciale pour une progression fluide du projet.
Pour améliorer la collaboration et l'organisation au sein de votre
référentiel GitHub, vous décidez d'exploiter les fonctionnalités de
liaison et de référencement de GitHub. Cela aidera à résoudre les
problèmes en double et à rationaliser la communication entre les membres
de l'équipe.

Dans cet laboratoire pratique, vous allez découvrir comment connecter et
gérer efficacement divers éléments au sein de votre référentiel GitHub
afin d'optimiser votre flux de travail de collaboration.

- Créer un référentiel : configurez un référentiel nommé
  skills-connect-the-dots pour vous entraîner à utiliser les
  fonctionnalités de liaison et de référencement de GitHub.

- Résoudre les problèmes de doublon (Duplicates Issues) : identifiez et
  résolvez les problèmes de doublon dans le référentiel.

- Trouver et fermer les problèmes interdépendants (Cross-Linked Issues)
  : Entraînez-vous à trouver et à fermer les problèmes interconnectés,
  en acquérant de l'expérience dans la gestion efficace des problèmes au
  sein du dépôt.

Exercice \#1 : Mettre en place un nouveau Repository (pour s'entraîner à
utiliser les fonctionnalités de liaison et de référencement de GitHub)

1.  Connectez-vous à votre compte GitHub.

2.  Naviguez jusqu'au lien suivant :
    https://github.com/skills/connect-the-dots

Dans cet atelier, vous allez créer le référentiel à l'aide d'un modèle
public « **skills-connect-the-dots** ».

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image1.jpeg)

3.  Sélectionnez **Create a new repository** dans le menu **Use this
    template**.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image2.jpeg)

4.  Entrez les détails suivants et sélectionnez **Create Repository**.

    - Nom du référentiel : **skills-connect-the-dots**

    - Type de référentiel : **Public**

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image3.jpeg)

Exercice \#2 : Trouver et fermer les problèmes liés

1.  Une fois le référentiel créé sur la page d'accueil, accédez à l'
    onglet **Problèmes (Issues)**.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image4.jpeg)

2.  Sur la page suivante, cliquez sur le problème (issue) **Welcome**.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image5.jpeg)

3.  Sur la page **Welcome \#1**, faites défiler la page jusqu'à **Add a
    comment**.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image6.jpeg)

4.  Entrez le Duplicate de \#2 en commentaire et fermez le problème
    (issue) \#1.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image7.jpeg)

5.  Attendez environ 20 pendant que GitHub Actions met automatiquement à
    jour la page avec l'état de fermeture.

![Une capture d'écran d'un chat Le contenu généré par l'IA peut être
incorrect.](./media/image8.jpeg)

Résumé:

Vous avez maintenant amélioré vos compétences en matière de navigation
dans les dépôts GitHub, amélioré votre capacité à gérer les problèmes et
optimisé les flux de travail de collaboration de votre équipe.
