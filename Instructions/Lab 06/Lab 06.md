**Laboratório 06: Melhore a colaboração com o GitHub: Encontre e conclua
as questões vinculadas**

Objetivos:

Imagine que você está trabalhando em um projeto colaborativo com uma
equipe de desenvolvimento, e gerenciar problemas e solicitações de pull
de forma eficiente é crucial para o andamento tranquilo do projeto. Para
melhorar a colaboração e a organização dentro do seu repositório GitHub,
você decide aproveitar os recursos de vinculação e referência do GitHub.
Isso ajudará a resolver problemas duplicados e agilizará a comunicação
entre os membros da equipe.

Neste laboratório prático, você vai explorar como conectar e gerenciar
de forma eficaz vários elementos dentro do seu repositório GitHub para
otimizar seu fluxo de trabalho colaborativo.

- Crie um repositório: configure um repositório chamado
  skills-connect-the-dots para praticar o uso dos recursos de vinculação
  e referência do GitHub.

- Resolva problemas duplicados: identifique e resolva problemas
  duplicados no repositório.

- Encontre e conclua problemas interligados: pratique encontrar e
  concluir problemas que estão interligados, ganhando experiência no
  gerenciamento eficaz de problemas dentro do repositório.

recursos de vinculação e referência do GitHub)

    https://github.com/skills/connect-the-dots
