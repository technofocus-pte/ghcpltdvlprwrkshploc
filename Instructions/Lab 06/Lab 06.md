**Laboratorio 06: Mejore la colaboración con GitHub: encuentre y cierre
los cross-linked issues**

Objetivos:

Imagine que está trabajando en un proyecto colaborativo con un equipo de
desarrollo, y gestionar issues y pull requests de manera eficiente es
crucial para un progreso fluido del proyecto. Para mejorar la
colaboración y la organización dentro de su repositorio de GitHub,
decide aprovechar las características de linking y referencing de
GitHub. Esto ayudará a resolver issues duplicados y a agilizar la
comunicación entre los miembros del equipo.

En este laboratorio práctico, explorará cómo conectar y administrar de
manera efectiva varios elementos dentro de su repositorio de GitHub para
optimizar su flujo de colaboración.

- Crear un repositorio: Configure un repositorio con el nombre
  skills-connect-the-dots para practicar el uso de las características
  de vinculación y referencia de GitHub.

- Resolver problemas duplicados: Identifique y resuelva los problemas
  duplicados dentro del repositorio.

- Encontrar y cerrar problemas con referencias cruzadas: Practique cómo
  encontrar y cerrar problemas que tienen referencias cruzadas,
  adquiriendo experiencia en la gestión efectiva de problemas dentro del
  repositorio.
