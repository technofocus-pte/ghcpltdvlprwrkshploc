**Lab 06: Verbessern der Zusammenarbeit mit GitHub: Finden und schließen
Sie die vernetzten Probleme**

Ziele:

Stellen Sie sich vor, Sie arbeiten an einem kollaborativen Projekt mit
einem Entwicklungsteam, und die effiziente Verwaltung von Issues und
Pull Requests ist entscheidend für einen reibungslosen
Projektfortschritt. Um die Zusammenarbeit und Organisation in Ihrem
GitHub-Repository zu verbessern, entscheiden Sie sich für die
Verknüpfungs- und Referenzierungsfunktionen von GitHub. Dies wird dazu
beitragen, doppelte Probleme zu beheben und die Kommunikation zwischen
den Teammitgliedern zu optimieren.

In diesem praxisorientierten Lab erfahren Sie, wie Sie verschiedene
Elemente in Ihrem GitHub-Repository effektiv verbinden und verwalten
können, um Ihren Workflow für die Zusammenarbeit zu optimieren.

- Erstellen eines Repositorys: Richten Sie ein Repository mit dem Namen
  skills-connect-the-dots ein, um die Verknüpfungs- und
  Referenzierungsfunktionen von GitHub zu üben.

- Beheben doppelter Probleme: Identifizieren und beheben Sie doppelte
  Probleme innerhalb des Repositorys.

- Vernetzte Issues finden und schließen: Üben Sie das Finden und
  Schließen von Issues, die vernetzt sind, und sammeln Sie Erfahrungen
  im effektiven Umgang mit Issues innerhalb des Repositorys.

Übung \#1: Einrichten eines neuen Repositorys (um die Verwendung der
Verknüpfungs- und Referenzierungsfunktionen von GitHub zu üben)

1.  Melden Sie sich bei Ihrem GitHub-Konto an.

2.  Navigieren Sie zu folgendem Link:
    https://github.com/skills/connect-the-dots

In diesem Lab erstellen Sie das Repository mithilfe einer öffentlichen
Vorlage "**skills-connect-the-dots**".

    repository** aus.

![Ein Screenshot eines Computers KI-generierte Inhalte können falsch
sein.](./media/image2.jpeg)

4.  Geben Sie die folgenden Details ein, und wählen Sie **Repository
    erstellen** aus.

    - Name des Repositorys: **skills-connect-the-dots**

    - Repository-Typ: **Public**

Übung \#2: Finden und schließen Sie die vernetzten Probleme

1.  Sobald das Repository auf der Startseite erstellt wurde, navigieren
    Sie zur Registerkarte **Issues**.

![Ein Screenshot eines Computers KI-generierte Inhalte können falsch
sein.](./media/image4.jpeg)

2.  Klicken Sie auf der nächsten Seite auf **Welcome**-Issue.

![Ein Screenshot eines Computers KI-generierte Inhalte können falsch
sein.](./media/image5.jpeg)

3.  Scrollen Sie auf der Seite **Welcome \#1** nach unten zum Fenster

![Ein Screenshot eines Computers KI-generierte Inhalte können falsch
sein.](./media/image6.jpeg)

4.  Duplicate of \#2 als Kommentar eingeben und Issue \#1 schließen

![Ein Screenshot eines Computers KI-generierte Inhalte können falsch
sein.](./media/image7.jpeg)

5.  Warten Sie etwa 20 Sekunden, während GitHub Actions die Seite

sein.](./media/image8.jpeg)

Zusammenfassung:

Sie haben jetzt Ihre Fähigkeiten beim Navigieren in GitHub-Repositorys
verbessert, Ihre Fähigkeit zur Verwaltung von Issues verbessert und die
Workflows für die Zusammenarbeit Ihres Teams optimiert.
