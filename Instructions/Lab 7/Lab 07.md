**ラボ 07: GitHub Codespaces と Visual Studio Code
を使用したコーディング**

目的：

あなたが開発者で、コラボレーションを促進し、ワークフローを合理化するためにクラウドでホストされる開発環境を必要とするプロジェクトに取り組んでいると想像してください。生産性を向上させ、開発セットアップをより効果的に管理するために、Visual
Studio Code で GitHub Codespaces
を使用することにしました。この設定により、開発環境をクラウドで直接作成およびカスタマイズできるため、チームとのコラボレーションやプロジェクト構成の効率的な管理が容易になります。

このハンズオンラボでは、次のことを行います:

- Codespace を開始する: 定義済みのテンプレートを使用して GitHub
  Codespace を作成して起動します。

- 構成のカスタマイズ: 開発ニーズに合わせて、codespace
  内のプロジェクト構成をカスタマイズします。

- Codespaces の管理: codespace
  を効率的に管理およびナビゲートし、スムーズで組織化された開発プロセスを保証します。

- コードをリポジトリにプッシュする: コードの変更を codespace から GitHub
  リポジトリにプッシュする練習をして、開発作業とバージョン管理を統合する能力を強化します。

演習 \#1: 新しいリポジトリを設定し、GitHub Codespace をスピンアップする)

1.  GitHub アカウントにサインインします。

2.  次のリンクを参照します:
    https://github.com/skills/code-with-codespaces

このラボでは、パブリック テンプレート "**skills-code-with-codespaces**"
を使用してリポジトリを作成します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image1.jpeg)

3.  「**このテンプレートを使用する**」メニューの「**Create a new
    repository**」 を選択します 。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image2.jpeg)

4.  次の詳細を入力し、「**Create Repository」**を選択します。

    - リポジトリ名: **skills-code-with-codespaces**

    - リポジトリの種類: **Public**

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image3.jpeg)

5.  リポジトリが作成されたら、「**Code」**ボタンをクリックします。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image4.jpeg)

6.  ポップアップ ウィンドウで**「Codespaces**」タブを選択し、「**the
    Create codespace on main」**ボタンをクリックします。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image5.jpeg)

**注:** codespace は新しいブラウザー タブで開きます。

7.  ブラウザーに VS Code Web
    ベースのエディターが表示され、以下に示すようにターミナルが存在するはずです。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image6.jpeg)

8.  codespace (仮想マシン) が自動的にスピンアップするまで 2
    分間待ちます。

![コンピューターのスクリーンショット AI

9.  **skills-code-with-codespaces**リポジトリに戻り、**「コード」**ボタンをクリックします。

![コンピューターのスクリーンショット AI

**注:** 新しく作成した codespace

10. 省略記号...アクティブなcodespace\*\*.\*\*

**注**: codespace名は、ケースによって異なる場合があります

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image9.jpeg)

11. ポップアップメニューの「**Open in Visual Studio
    Code」**を選択します。

![コンピューターのスクリーンショット AI

    codeアプリケーションでcodespaceを開くための確認を求められます。「**Open

![コンピューターのスクリーンショット AI

    の拡張機能をインストールするように求められるので、「**Install

![コンピューターのスクリーンショット AI

![ログインフォームのスクリーンショット AI

![コンピューターのスクリーンショット AI

演習 \#2: codespace からリポジトリにコードをプッシュする

1.  VS Code エクスプローラー ウィンドウの codespace 内から、index.html
    fileを選択します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image16.jpeg)

2.  h1 ヘッダーを以下に置き換えます：

\<h1\>Hello from the codespace!\</h1\>

3.  ファイルを保存します。

**注:** ファイルは自動保存されます。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image17.jpeg)

4.  VS Code
    ターミナルを使用して、以下のコミット・メッセージを入力してファイル変更をコミットします：

> git commit -a -m "Adding hello from the codespace!"

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image18.jpeg)

5.  変更をリポジトリにプッシュバックします。VS Code
    ターミナルから、次のように入力します：

git push

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image19.jpeg)

6.  VS の新しいコードがリポジトリにプッシュされました！

7.  リポジトリのホームページに戻り、index.htmlを表示して、新しいコードがリポジトリにプッシュされたことを確認します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image20.jpeg)

8.  約 20 秒待ってから、これを更新すると、GitHub Actions
    は自動的に次のステップに更新されます。

概要：

これで、GitHub Codespaces と Visual Studio Code を使用して、

- 定義済みのテンプレートを使用して GitHub Codespace
  を作成して起動します。

- コードをリポジトリにプッシュする: コードの変更を codespace から GitHub
  リポジトリにプッシュする練習をして、開発作業とバージョン管理を統合する能力を強化します。
