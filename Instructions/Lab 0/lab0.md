Tâche 2 : S'inscrire à la licence d'essai GitHub Copilot Pro :
l'abonnement d'essai est nécessaire lorsque vous épuisez la limite
mensuelle de l'offre gratuite.

**Remarque :** GitHub a commencé à proposer (à partir du dernier
trimestre 2024) l'offre gratuite de GitHub Copilot par défaut à tous les
utilisateurs de GitHub, à la fois dans Github.com et dans l'IDE Visual
Studio Code. L'offre gratuite comporte des limites d'utilisation
mensuelles en termes de nombre de complétions de code et d'interactions
avec le chat Copilot. Une fois que vous aurez épuisé les limites, vous
serez invité à vous inscrire à un essai de Copilot Pro (si vous n'avez
pas encore profité de l'offre d'essai, un abonnement d'essai de 30 jours
que vous pouvez souscrire en suivant les étapes indiquées ci-dessous).
Assurez-vous d'annuler votre licence avant la fin de la période d'essai
pour éviter d'être facturé.

1.  Ouvrez un nouvel onglet dans votre navigateur et accédez à
    S'inscrire à GitHub Copilot -
    **https://github.com/github-copilot/signup**

2.  Cliquez sur le bouton **Get access to GitHub Copilot**.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image10.jpeg)

3.  Entrez les informations de facturation avec votre carte de crédit
    personnelle, puis cliquez sur **Save**.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image11.jpeg)

4.  Entrez vos informations de facturation, puis cliquez sur le bouton
    **Save payment information**.

![Une capture d'écran d'un ordinateur Le contenu généré par l'IA peut
être incorrect.](./media/image12.jpeg)

**IMPORTANT :** Assurez-vous de désactiver le compte une fois que vous
avez terminé les exercices pratiques pour éviter de facturer
l'utilisation.
