Tarefa 2: Assinar a licença de teste do GitHub Copilot Pro - A
assinatura de teste é necessária quando você ultrapassar o limite mensal
do plano gratuito.

**Observação:** O GitHub começou a oferecer (a partir do último
trimestre de 2024) o plano gratuito do GitHub Copilot por padrão para
todos os usuários do GitHub, tanto no GitHub.com quanto no Visual Studio
Code IDE. O plano gratuito possui alguns limites mensais de uso em
termos de número de conclusões de código e interações no Copilot Chat.
Quando você atingir os limites, será solicitado que se inscreva para um
teste do Copilot Pro (se você ainda não tiver aproveitado a oferta de
teste — uma assinatura de teste de 30 dias, que você pode obter seguindo
os passos abaixo). Certifique-se de cancelar sua licença antes do final
do teste para evitar cobranças.

1.  Abra uma nova guia no seu navegador e acesse Inscreva-se no GitHub
    Copilot - **https://github.com/github-copilot/signup**

2.  Clique no botão **Get access to GitHub Copilot**.

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image10.jpeg)

3.  Insira as informações de faturamento com seu cartão de crédito
    pessoal e clique em **Save**.

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image11.jpeg)

4.  Insira suas informações de faturamento e clique no botão **Save
    payment information**.

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image12.jpeg)

**IMPORTANTE:** Certifique-se de desativar a conta após concluir os
laboratórios para evitar cobrança pelo uso.
