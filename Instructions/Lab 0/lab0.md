タスク 2: GitHub Copilot Pro 試用版ライセンスにサインアップする -
試用版サブスクリプションは、毎月の無料レベルの制限を使い果たした場合に必要になります。

**注:** GitHub は、Github.com と Visual Studio Code IDE の両方のすべての
GitHub ユーザーに、既定で (2024 年の最終四半期から) GitHub Copilot
無料レベルの提供を開始しました。無料レベルには、コード補完数と Copilot
チャット対話の点で、毎月の使用制限があります。制限を使い果たすと、Copilot
Pro トライアルにサインアップするように求められます (トライアル
オファーをまだ利用していない場合は、以下の手順に従ってサインアップできる
30 日間のトライアル
サブスクリプション)。請求されないように、試用期間が終了する前にライセンスをキャンセルしてください。

1.  ブラウザーで新しいタブを開き、GitHub Copilot へのサインアップ -
    **https://github.com/github-copilot/signup** に移動します。

2.  「**Get access to GitHub Copilot** 」 ボタンをクリックします。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image10.jpeg)

3.  個人のクレジットカードで請求情報を入力し、「**Save**」をクリックします。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image11.jpeg)

4.  請求情報を入力し、「**Save payment
    information**」ボタンをクリックします。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image12.jpeg)

**重要:**
使用量に対する請求を避けるために、ラボの完了後にアカウントを無効にしてください。

タスク 3: Visual Studio Code に必要な拡張機能をインストールする

1.  Windows の 「スタート」メニュー から Visual Studio Code
    を開きます。**「Accounts -\> Backup and Sync
    Settings** **」**をクリックし、「**Sign in**」を選択します**。**

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image13.jpeg)

2.  「**Sign in with Github**」 オプションを選択します。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image14.jpeg)

3.  ブラウザーをセクトし、Copilot が有効な Github
    アカウントでサインインします。

![コンピューターのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image15.jpeg)

![ログインページのスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image16.jpeg)

![電話番号のスクリーンショット AI
が生成したコンテンツは間違っている可能性があります。](./media/image17.jpeg)

5.  「Visual Studio Code」 をクリックします。
