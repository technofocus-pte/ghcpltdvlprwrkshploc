Attività 2: Iscrizione alla licenza di prova di GitHub Copilot Pro:
l'abbonamento di prova è necessario quando si esaurisce il limite del
livello gratuito mensile.

**Nota:** GitHub ha iniziato a offrire (a partire dall'ultimo trimestre
del 2024) il livello gratuito di GitHub Copilot per impostazione
predefinita a tutti gli utenti GitHub sia in Github.com che nell'IDE di
Visual Studio Code. Il piano gratuito prevede alcuni limiti di utilizzo
mensili in termini di numero di completamenti del codice e interazioni
in chat con Copilot. Una volta esauriti i limiti, ti verrà chiesto di
iscriverti a una versione di prova di Copilot Pro (se non hai già
usufruito dell'offerta di prova, un abbonamento di prova di 30 giorni
che puoi sottoscrivere seguendo i passaggi indicati di seguito).
Assicurati di annullare la licenza prima della fine del periodo di prova
per evitare di ricevere addebiti.

1.  Aprire una nuova scheda nel browser e andare su Signup to GitHub
    Copilot - **https://github.com/github-copilot/signup**

2.  Fare clic sul pulsante **Get access to GitHub Copilot**.

![Uno screenshot di un computer I contenuti generati dall'intelligenza
artificiale potrebbero non essere corretti.](./media/image10.jpeg)

3.  Inserire i dati di fatturazione con la vostra carta di credito
    personale e poi cliccare su **Save**.

![Uno screenshot di un computer I contenuti generati dall'intelligenza
artificiale potrebbero non essere corretti.](./media/image11.jpeg)

4.  Inserire i vostri dati di fatturazione e quindi fare clic sul
    pulsante **Save payment information**.

![Uno screenshot di un computer I contenuti generati dall'intelligenza
artificiale potrebbero non essere corretti.](./media/image12.jpeg)

**IMPORTANTE:** assicurati di disattivare l'account dopo aver completato
