任務 2：註冊 GitHub Copilot Pro 試用許可證 -
用盡每月免費層限制時，需要試用訂閱。

**注意：**默認情況下，GitHub 開始向 Github.com 和 Visual Studio Code IDE
中的所有 GitHub 用戶提供（從 2024 年最後一個季度開始）GitHub Copilot
免費層。免費套餐在代碼完成次數和 Copilot
聊天交互方面有一些每月使用限制。用盡限制後，系統將提示您註冊 Copilot Pro
試用版（如果您尚未使用試用優惠，則可以按照下面給出的步驟註冊 30
天試用訂閱）。請務必在試用期結束前取消許可證，以避免被計費。

1.  在瀏覽器中打開一個新選項卡，然後轉到註冊 GitHub Copilot -
    **https://github.com/github-copilot/signup**

2.  單擊“**Get access to GitHub Copilot**”按鈕。

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image10.jpeg)

3.  使用您的個人信用卡輸入賬單信息，然後單擊 **Save**。

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image11.jpeg)

4.  輸入您的賬單信息，然後單擊 **Save payment information** 按鈕。 

![A screenshot of a computer AI-generated content may be
incorrect.](./media/image12.jpeg)

**重要提示：**請務必在完成實驗室後停用該帳戶，以避免按使用量計費。
