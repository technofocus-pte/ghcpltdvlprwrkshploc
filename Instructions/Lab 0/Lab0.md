Aufgabe 2: Registrieren Sie sich für die GitHub Copilot Pro-Testlizenz:
Das Testabonnement ist erforderlich, wenn Sie das monatliche Limit für
das kostenlose Kontingent ausgeschöpft haben.

**Hinweis:** GitHub bietet seit dem letzten Quartal 2024 standardmäßig
allen GitHub-Benutzern sowohl in Github.com als auch in Visual Studio
Code IDE den kostenlosen Tarif GitHub Copilot an. Das kostenlose
Kontingent hat einige monatliche Nutzungsbeschränkungen in Bezug auf die
Anzahl der Code-Vervollständigungen und Copilot-Chat-Interaktionen.
Sobald Sie die Limits ausgeschöpft haben, werden Sie aufgefordert, sich
für eine Copilot Pro-Testversion anzumelden (wenn Sie das Testangebot
noch nicht in Anspruch genommen haben, ein 30-tägiges Testabonnement,
das Sie mit den unten angegebenen Schritten abschließen können). Stellen
Sie sicher, dass Sie Ihre Lizenz vor Ablauf der Testversion kündigen, um
eine Belastung durch eine Rechnung zu vermeiden.

1.  Öffnen Sie einen neuen Tab in Ihrem Browser und gehen Sie zu
    Anmelden bei GitHub Copilot -
    **https://github.com/github-copilot/signup**

2.  Klicken Sie auf die Schaltfläche **Get access to GitHub Copilot**.

![Ein Screenshot eines Computers KI-generierte Inhalte können falsch
sein.](./media/image10.jpeg)

3.  Geben Sie die Rechnungsinformationen mit Ihrer persönlichen
    Kreditkarte ein und klicken Sie dann auf **Save**.

![Ein Screenshot eines Computers KI-generierte Inhalte können falsch
sein.](./media/image11.jpeg)

4.  Geben Sie Ihre Zahlungsinformationen ein und klicken Sie dann auf
    die Schaltfläche **Save payment information**.

![Ein Screenshot eines Computers KI-generierte Inhalte können falsch
sein.](./media/image12.jpeg)

**WICHTIG:** Stellen Sie sicher, dass Sie das Konto deaktivieren,
nachdem Sie die Labs abgeschlossen haben, um eine Abrechnung für die
Nutzung zu vermeiden.
